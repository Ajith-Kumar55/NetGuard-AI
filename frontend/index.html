About NetGuard AI

Machine Learning Based Network Intrusion Detection System

📌 Purpose

NetGuard AI is a capstone-level machine-learning Network Intrusion Detection System designed to analyze network packet captures and traffic connection records, classify them using a 2-stage hierarchical classifier, explain threat predictions via SHAP, and persist security logs into a relational database.

🛠️ Technology Stack

Data & ML: Python, Pandas, Scikit-learn, Scapy, SHAP, Joblib
Backend: FastAPI, Uvicorn, Pydantic, SQLAlchemy, OAuth2 JWT, Passlib
Frontend: HTML5, CSS3, JavaScript (ES6+), Chart.js
Database & Container: SQLite, Docker
